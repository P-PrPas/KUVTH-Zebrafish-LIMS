ให้ VETKU ส่ง OTP ผ่านอีเมล KU

เป้าหมายคือขอรหัส OTP แล้วได้รับอีเมลที่ส่งโดย backend ของ VETKU โดยเก็บ credential ไว้ใน `.env` บนเครื่องของคุณเท่านั้น

ข้อสำคัญ: อย่าใส่รหัสผ่าน KU/Nontri ปกติลงใน `.env` และอย่าส่ง App Password ในแชตหรือ commit ลง Git บัญชี `@ku.th` เป็น KU-Google; KU ระบุให้เข้าใช้ผ่าน mail.ku.th ส่วน Google ระบุว่า SMTP ใช้ App Password และองค์กรโรงเรียนอาจปิดความสามารถนี้ได้.

ทำทีละขั้น

  1. ยืนยันว่าบัญชีเป็น KU-Google
    เปิด mail.ku.th แล้วลงชื่อเข้าใช้ด้วย peerapas.c@ku.th ถ้าเข้าไม่ได้ ให้แก้ปัญหาบัญชีกับ KU ก่อนตั้ง SMTP
  2. เปิดการยืนยันตัวตน 2 ขั้น (ถ้ายังไม่ได้เปิด)
    ไปที่ Google Account → Security และเปิด 2-Step Verification หากนโยบาย KU อนุญาต
  3. ลองสร้าง App Password
    เปิด App Passwords ขณะลงชื่อเข้าใช้บัญชี KU-Google นี้ ตั้งชื่อเช่น VETKU SMTP แล้วสร้างรหัสเฉพาะสำหรับระบบนี้ Google จะแสดงรหัสครั้งเดียว ให้คัดลอกเก็บไว้ชั่วคราวเพื่อกรอกลง `.env` ในขั้นตอนถัดไป ถ้าไม่มีเมนูนี้ อย่าใช้รหัส KU ปกติ ให้ข้ามไปขั้น 6
  4. เปิดไฟล์ `.env` ในโฟลเดอร์โปรเจ็กต์
    ใน PowerShell ที่โฟลเดอร์ VETKU ใช้คำสั่งนี้ มันจะสร้าง `.env` จากตัวอย่างเฉพาะเมื่อยังไม่มีไฟล์อยู่แล้ว: 
    if (-not (Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
    ถ้ามี `.env` อยู่แล้ว ให้แก้เฉพาะบรรทัด `MAIL_...` เพื่อรักษาค่าอื่นของเครื่องไว้
  5. กรอกค่าตามนี้ใน `.env` 
    MAIL_SMTP_HOST=smtp.gmail.com
MAIL_SMTP_PORT=587
MAIL_SMTP_USERNAME=peerapas.c@ku.th
MAIL_SMTP_PASSWORD=วาง-App-Password-ตรงนี้-เฉพาะในไฟล์-local
MAIL_SENDER_EMAIL=peerapas.c@ku.th
MAIL_USE_SSL=false
    ถ้า Google แสดง App Password แยกเป็นกลุ่ม ให้กรอกเป็นตัวอักษรต่อกันโดยไม่มีช่องว่าง หากรหัสมีอักขระพิเศษ ให้ครอบค่าด้วยเครื่องหมายคำพูดตามรูปแบบ dotenv ที่โปรเจ็กต์ใช้
  6. บันทึกไฟล์และรีสตาร์ต backend
    ถ้ารันโปรเจ็กต์ด้วย Docker Compose จากโฟลเดอร์หลัก ให้ใช้ docker compose up -d --build api ถ้ารัน backend ใน terminal แยก ให้หยุดและเริ่ม process นั้นใหม่ เพื่อโหลด environment ใหม่
  7. ทดสอบส่งจริง
    เปิดหน้า login ของ VETKU ขอ OTP สำหรับ peerapas.c@ku.th แล้วดู Inbox และ Spam ข้อความแจ้งว่า SMTP configured เพียงบอกว่ามี host/sender; การได้รับ OTP เป็นการยืนยันการเชื่อมต่อจริง

ถ้าส่งไม่ผ่าน

  • ไม่มีเมนู App Password: บัญชี work/school อาจถูกองค์กรปิดไว้ ติดต่อ KU IT/OCS อย่าใช้รหัสบัญชีปกติแทน
  • SMTP แจ้ง username/password ไม่ผ่าน: สร้าง App Password ใหม่ ตรวจว่าชื่อผู้ใช้เป็นอีเมลเต็ม และ `MAIL_USE_SSL=false` เมื่อใช้พอร์ต 587
  • ส่งได้แต่ผู้รับไม่เห็น: ตรวจ Spam และยืนยันว่า `MAIL_SENDER_EMAIL` เป็นบัญชีที่ยืนยันตัวตนหรือ alias ที่ได้รับอนุญาต
  • จะขอความช่วยเหลือเรื่อง error ให้ส่งเฉพาะข้อความ error หลังลบรหัสผ่าน, OTP, token และข้อมูลส่วนบุคคลออกแล้ว

ถ้า KU ปิด App Password

ส่งคำถามนี้ให้ KU IT/OCS ผ่าน AskMe KU หรือช่องทางสนับสนุนที่หน่วยงานกำหนด:

“ต้องการให้ backend ของระบบ VETKU ส่ง OTP และ invitation email จาก KU-Google `peerapas.c@ku.th` ได้หรือไม่ บัญชีนี้ไม่มีเมนู App Password ให้ใช้ ขอทราบว่าควรใช้ SMTP AUTH แบบใด หรือขออีเมลสำหรับระบบ/SMTP relay ได้หรือไม่ หากใช้ relay กรุณาแจ้ง hostname, port, TLS/SSL mode, authentication method, sender address ที่อนุญาต และเงื่อนไข allowlist IP”

สำหรับระบบระยะยาว OCS มีบริการอีเมลสำหรับระบบแยกจาก mailbox บุคคล ควรถามวิธีขอใช้และข้อจำกัดปัจจุบันก่อนย้ายผู้ส่ง

จำสั้น ๆ: `smtp.gmail.com` + `587` + STARTTLS (`MAIL_USE_SSL=false`) + full KU email + App Password
