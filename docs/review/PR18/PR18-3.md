🟡 ข้อสังเกตเรื่องเลข lot อัตโนมัติ (ไม่ block แต่ควรบันทึกไว้)

ทดสอบแล้วทำงานถูกตามที่ออกแบบ: นับเลขข้ามการทดลองที่ใช้ชุดไข่และวันเดียวกัน, ไม่สนใจ lotNo ที่ client ส่งมา, แม่แบบได้เลขไม่ซ้ำ, ตอน activate ยังใช้เลขเดิม, และ concurrency ปลอดภัยเพราะทุก mutation ล็อกแถวเดียวกัน (FOR UPDATE)

ข้อที่ควรรู้:
- เลขในการทดลองเดียวกันมีช่องว่าง: ถ้า A ได้ lot 1, 3, 4 เพราะ B ได้ 2 ไปก่อน รหัสตัวอ่อนจะเป็น ..._4_1 ควรยืนยันกับลูกค้าว่าต้องการแบบนี้
- เลขซ้ำได้หลังแก้การทดลอง: ถ้าแก้ชุดไข่หรือวันที่ของการทดลองหลังสร้าง lot แล้ว จะได้ lot "1" สองตัวใน scope เดียวกัน (ทดสอบจริงแล้ว) ทางแก้คือห้ามแก้สองฟิลด์นี้เมื่อมี lot แล้ว หรือบันทึกไว้เป็นข้อจำกัด
- ตอน offline หน้าจอแสดงเลข lot แบบคาดการณ์ ถ้ามีคนอื่นสร้าง lot ไปก่อน เลขจริงหลัง sync อาจต่างจากที่เห็น
