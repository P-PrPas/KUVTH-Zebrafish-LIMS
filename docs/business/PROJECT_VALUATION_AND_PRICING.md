**ทำไม Import Excel อยู่ในรอบนี้:** พอเปิดใช้ระบบ แลปต้องมีข้อมูลการทดลองเดิมอยู่ในระบบเพื่อทดลองต่อได้ทันที — นำเข้าข้อมูลจึงจบพร้อมการส่งมอบ

**ทำไม Login เลื่อนเป็นเฟส 2 ได้:** SRS ไม่ได้บังคับ login ใน v1 (ใช้ operator selector + device_id) · ระบบใช้งานจริงได้โดยไม่มี login · การลงทะเบียน SSO กับ IT มหาลัยใช้เวลาไม่แน่นอน จึงเหมาะเป็นเฟสของตัวเอง

**ทำไมราคานี้ไม่ได้ขายถูกเกินไป:** เทียบมูลค่างานจริง (71 API, 18 หน้าจอ, dual-DB, offline, dashboard, audit) ราคานี้ต่ำกว่าตลาดมากอยู่แล้ว · import กับ login คิดที่อัตราต้นทุน (ประมาณ 1,300–1,500 บาท/คน-วัน) แล้ว — ต่ำกว่านี้ผู้พัฒนาขาดทุนเวลา

## 3. เฟส 2 (ภายหลัง) — Login + Admin พื้นฐาน (9,000)

> เสนอเป็นใบเสนอราคาแยก ทำหลังระบบรอบแรก go-live และหลังมหาลัยอนุมัติ SSO

| # | งาน | รายละเอียด | ราคา |
|---|---|---|---:|
| L1 | เชื่อมต่อ SSO ล็อกอินมหาวิทยาลัย | OAuth2/OIDC client · callback · จัดการ session · ประสานงาน + ทำเรื่องขอลงทะเบียน service กับ IT มหาลัย | 3,500 |
| L2 | ระบบสิทธิ์ (พื้นฐาน) | 2–3 บทบาท (Admin / ผู้ใช้ทั่วไป / อ่านอย่างเดียว) · บังคับสิทธิ์จุดสำคัญ (แก้ master data, ลบ/แก้ย้อนหลัง, ตั้งค่าระบบ) | 2,000 |
| L3 | หน้าจอผู้ดูแลระบบ (Admin) | รายชื่อผู้ใช้ · กำหนด/เปลี่ยนบทบาท · เปิด/ปิดบัญชี · ผูกบัญชีล็อกอินเข้ากับระเบียน Operator เดิม | 2,500 |
| L4 | ปรับระบบเดิม + ทดสอบ + เอกสาร | ดึง operator จากผู้ใช้ที่ล็อกอิน (ยังเก็บ device_id) · audit การเข้าใช้ · อัปเดตคู่มือ | 1,000 |
| | **รวม** | | **9,000** |

**หมายเหตุ:**
- ราคานี้อิงการเชื่อมต่อแบบ OAuth2/OIDC มาตรฐาน — หากมหาวิทยาลัยกำหนดวิธีอื่น (SAML, API gateway, ค่าธรรมเนียม) คิดเพิ่มตามจริง
- เป็นสิทธิ์แบบพื้นฐาน 2–3 บทบาท · ถ้าลูกค้าต้องการสิทธิ์ละเอียดครบ 5 บทบาทตาม persona บังคับทุก endpoint = งานเพิ่ม ~4,000–6,000 (หัวข้อ 4)

## 6. เช็คลิสต์ก่อนส่งใบเสนอราคา

- [ ] **ล็อก scope เป็นลายลักษณ์อักษร** หลังรอบ feedback นี้ — สรุปว่าระบบ 44k ครอบคลุมอะไรบ้าง แล้วให้ลูกค้า/อาจารย์ยืนยัน
- [ ] **กำหนดจำนวนรอบแก้** — เช่น "รวมการปรับตาม feedback 2 รอบหลัง draft แรก · ฟีเจอร์ใหม่หลัง scope ยืนยันแล้ว = งานเพิ่ม"
- [ ] **ระบุขอบเขต Import ให้ชัด** — "นำเข้าเฉพาะข้อมูล active จาก clean table ไฟล์เดียวที่แลปยืนยัน · ประวัติที่จบแล้วและ raw 4 ไฟล์ = งานแยก · ถ้า reconcile ไม่ตรง 100% เพราะข้อมูลต้นทางขัดกันเอง ไม่ถือเป็นข้อบกพร่อง"
- [ ] **Login/Admin = เฟส 2 แยกใบเสนอราคา** · ระบบรอบแรก go-live ได้โดยไม่ต้องรอ
- [ ] **เคลียร์กับอาจารย์:** เงินเข้าใคร · มีส่วนแบ่งไหม · ใครถือ production/backup หลังส่งมอบ
- [ ] **ขอ non-cash:** หนังสือรับรองการปฏิบัติงาน · สิทธิ์ portfolio / senior project · acknowledgements ใน paper ที่ใช้ข้อมูลจากระบบ
- [ ] **ช่องทางจ่ายเงิน:** จ้างเหมาบริการ + ใบเสนอราคา + ใบส่งมอบงาน · หัก ณ ที่จ่าย 1–3% · ออกใบรับเงิน
