# ชุดเอกสารนำเข้าข้อมูล

ชุดปัจจุบันคือ **รุ่น 5** อยู่ใน [v5](v5/) ชุดส่งให้ลูกค้ามีเพียง 3 ไฟล์:

- [Excel การทดลอง v5](v5/experiment-template-v5.xlsx)
- [Excel ทะเบียนปลา v5](v5/registry-template-v5.xlsx)
- [คู่มือ PDF](v5/คู่มือการกรอกข้อมูล-v5.pdf)

ลูกค้าเป็นผู้กรอกข้อมูลเอง กรณีไม่แน่ใจให้เว้นช่องนั้นและจด “รอตรวจ: …” ในหมายเหตุของรายการ
ส่งไฟล์คืนผู้ประสานงานที่ส่งแบบฟอร์มให้ทางช่องทางเดิม ไม่ต้องแยกแจ้งทุกจุด
คู่มือมี 13 หน้า โดยหัวข้อเตรียมข้อมูลเดิมอยู่หน้า 3–5 แยกเรื่องวันที่และเวลา ผลเอ็มบริโอ และทะเบียนปลา
ต้นฉบับข้อความของสามหน้านี้อยู่ใน [manual-legacy-preparation-v5.html](tools/manual-legacy-preparation-v5.html)
ลูกค้ายืนยันแล้วว่า Day1 ของเอ็มบริโอคือวันปฏิทินถัดจากวันกระตุ้น ไฟล์เดิมที่มีเฉพาะเวลา
ให้ใช้วันที่กระตุ้น + n วันสำหรับ Day n เช่น กระตุ้น 24/04/2026 แล้ว Day1 เวลา 13 คือ 25/04/2026 13:00
กฎนี้ใช้เฉพาะเอ็มบริโอ ข้อมูลปลาเก่ายังคงไม่คำนวณวันที่ตรวจจาก DOB+n
คำว่า Discarded/Dead ที่ยังไม่ทราบสภาพหรือการจัดการต้องรอยืนยัน ไม่เลือกคู่รหัสแทนลูกค้า

รุ่น 5 ใช้ 1=มีชีวิต และ 0=ตาย ทั้งเอ็มบริโอและปลา ตามคำยืนยันล่าสุด
แยกไฟล์การทดลองตามวันที่ ผู้ทำ และกลุ่มทดลอง ข้อมูล V1 ที่ไม่ทราบกลุ่มให้เว้นไว้
ข้อมูลปลาเก่าที่ไม่มีวันที่ตรวจไม่ต้องกรอกผลรายวัน และไม่คำนวณวันที่จาก DOB+n
ไม่มี QC/ENU และนำช่อง Injection ออกจากแบบฟอร์มรุ่นนี้ โดยคง backend เดิมไว้

## รุ่น 4 ที่เก็บไว้

ไฟล์ใน [current](current/GUIDE.md) เป็นชุดรุ่น 4 ที่เก็บไว้เทียบ ไม่ได้เขียนทับ
Excel รุ่นนั้นยังใช้ชื่อ experiment-template-final.xlsx และ registry-template-final.xlsx
คำว่า final เป็นชื่อส่งมอบในรอบก่อน ไม่ได้หมายถึงรุ่น 5
ห้ามอ่านข้ามรุ่น เพราะความหมายเลข 0/1 ของเอ็มบริโอต่างกัน
แผน improve-plan.md ที่รากโฟลเดอร์เป็นประวัติรุ่น 4 ไม่ใช่ข้อกำหนดชุดส่งมอบรุ่น 5
