# การยกระดับหน้าจอตามผลรีวิว

ทำครบทั้ง 6 ส่วนบน `feat/kuvacb-redesign-v2` ใน repository หลัก

## สิ่งที่เปลี่ยน

1. ข้อมูลอ้างอิง: เปลี่ยนปุ่ม 7 หมวดที่ซ้อนกันบนมือถือเป็น selector ที่มี label ส่วน desktop ใช้ navigation แนวตั้งและพื้นที่เนื้อหาด้านข้าง การเปลี่ยนหมวดยังใช้ state และการโหลดเดิม รายการ/แก้ไข/เลิกใช้และฟอร์มทั้ง 7 หมวดยังคงอยู่
2. รายงาน: ใช้ตรา KUVACB พร้อมหัวเอกสาร ตัวกรอง เวลาสร้างแบบ Bangkok UTC+7 และเวอร์ชันเวลามาตรฐาน แยก KPI หลัก 4 รายการออกจากข้อมูลประกอบ 7 รายการ ทำหัวข้อและคอลัมน์ไทยให้ตรงกับภาษา หน่วยเปอร์เซ็นต์อยู่กับตัวเลข ปรับพื้นที่ของตัวเลือกไฟล์และปุ่มดาวน์โหลดให้ชัดขึ้น
3. ส่วนหัวมือถือ: ย่อ logo/navigation และรวมผู้ปฏิบัติงาน ภาษา และบัญชีไว้แถวเดียว สถานะเครือข่าย/บันทึกยังแสดงครบ ชุดตรวจ 375px ลดส่วนหัว sidebar + topbar จากประมาณ 275px เป็น 209px โดยไม่ลดปุ่มควบคุมต่ำกว่า 44px
4. ทะเบียนทดลองและปลา: วันแสดงเป็น DD/MM/YYYY เช่นเดียวกับวันที่ใน Audit ข้อมูลปลา 5 ช่องบนมือถือให้ช่องสุดท้ายเต็มแถว และจัดเส้นแบ่ง/วันที่/สถานะ/ปุ่มใน timeline ให้ชัดขึ้น ไม่มีช่องว่างหนึ่งช่องเหมือนเดิม รูปแบบวันใน input และ payload ไม่เปลี่ยน
5. Guest: ใช้หัวองค์กร ชื่อหน้าและข้อความสิทธิ์ตรงหน้าที่ จัด KPI เป็น 3 × 2 บน desktop และ 2 × 3 บนมือถือ พร้อมจัดปุ่มบัญชีให้มีลำดับชัด ใช้ข้อมูลรวมที่ Guest เข้าถึงอยู่แล้ว
6. ภาษาและรายละเอียดร่วม: เปลี่ยนคำขวัญ Login เป็น “ระบบงานวิจัยปลาม้าลาย” ทำแท็บสมาชิก/ข้อความลองใหม่/รายงานไทยให้สม่ำเสมอ ใช้ฟอนต์ สี และ components เดิม ไม่มี dependency หรือ animation ต่อเนื่องเพิ่ม

## การตรวจ

- Full frontend suite ผ่าน 192 tests ใน 27 files (`--maxWorkers=1`) รวม test วัน Bangkok และการเปลี่ยนหมวดด้วย selector ใหม่ Tests ที่เคยผูกข้อความ/DOM เดิมปรับให้ตรวจ metadata/ข้อมูลและการใช้งานใหม่
- รอบ full suite ระหว่าง Docker build มี timeout ใน workflow/dashboard จึงทดสอบซ้ำแบบ worker เดียวหลัง build เสร็จ ผ่านโดยไม่ขยาย timeout
- Biome, TypeScript และ production build ผ่าน Vite ยังคงแจ้ง bundle มากกว่า 500kB ตามเดิม
- [ชุด browser checks](polish-checks.json) ใช้ compiled Docker frontend port 5173, isolated headless Chrome และ API fixtures มี 103 checks (97 checks หลักและ 6 checks รายงาน/print รอบสุดท้าย) ครอบคลุม 11 หน้าหลักที่ 1440/820/375/320px, 7 หมวดข้อมูลอ้างอิง, Guest grid, ข้อมูลปลา, report KPI และ popup ผู้ปฏิบัติงาน/บัญชี ทั้งไทยและรายงานอังกฤษ
- ภาพ login/dashboard ยังไม่มี animation และ footer sidebar ที่ถอดออกไม่ถูกเพิ่มกลับ
- ตรวจ PDF A4 ภาษาไทยและอังกฤษจาก browser อย่างละ 4 หน้า และ render ทุกหน้า ปรับให้หัวคอลัมน์ตัดบรรทัดในตาราง 12 คอลัมน์ หัวตารางซ้ำเมื่อขึ้นหน้าใหม่ และไม่แบ่งแถวของตาราง/แถว loss chart กลางหน้า ข้อความชวนกดกราฟไม่พิมพ์ลงเอกสาร พื้นกระดาษเป็นสีขาว ตรวจ text bounds ไม่พบข้อความนอกหน้า
- Rebuild/recreate เฉพาะ frontend ด้วย `--no-deps` ไม่ seed ซ้ำ ไม่เปลี่ยน API/PostgreSQL หรือ volumes
